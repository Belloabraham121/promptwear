# Driplab Landing V2: ChatGPT Image Prompts

Each image has **one prompt**. Copy the whole box, paste it into ChatGPT, then download the result and save it under the **file name** shown.

Put every file in `client/public/landing/v2/`.

**How to use it:**
- Send one prompt per message.
- Start a **new chat for each section**, so the images in a section match each other.
- If an image comes out well, keep going in the same chat. If one comes out wrong, reply "try again, same style".
- ChatGPT makes images in three shapes: **landscape**, **portrait** or **square**. Each prompt already asks for the right shape, and I'll crop to the exact size when building.
